Know every handoff

Architecture & source flow.

Small programs, explicit files, and atomic replacement make the system observable and recoverable.

Weather product pipeline

WeatherLink Live → weather.py → weather.txt ───────────────┐
                                                           ├→ voice converter → generate.sh → current.wav
AWC GFA → get_clouds_from_awc.py → clouds.json ───────────┤
                                                           ├→ text converter → current_sms.txt → PNG
HackRF / Airspy → click_listen.py → USB relay + radio ←────┘

A single snapshot feeds the voice, text, and graphic. Temporary files move into place only after they are complete. A failed station refresh does not touch the last observation, so file age remains honest.

What happens after five clicks

Calibrate

The receiver measures a local noise floor and calculates on/off thresholds.

Qualify

Carrier transitions must satisfy the minimum quiet and click-gap timing.

Count

Five qualified clicks inside the configured window become one accepted request.

Respond

When enabled, receive pauses, PTT closes, the report plays, PTT opens, and receive restarts.

Cool down

A fixed cooldown prevents an immediate repeated transmission.

Earlier generations

The root, v2, and v4 directories preserve Arduino and analog-detector approaches that helped the project evolve. They are valuable history, but new builds should start in v5-sdr-usb-relay.
