Full MyAWOS

A richer station toolchain.

The full edition keeps the click-to-weather core, then adds freshness enforcement, operational reporting, optional monitoring, and configurable integrations.

Weather

Direct local observations

WeatherLink Live data is read over the LAN. Discovery can be configured, but no special WeatherLink Python library is required.

Safety

Stale-data cutoff

The station timestamp controls freshness. After 12 hours without a valid response, all public products switch to the no-weather message.

Aviation Weather Center

Estimated cloud layers

GFA cloud layers are labeled AWC Estimated, cached, locked against overlapping jobs, and requested no more than every 30 minutes.

Products

One snapshot, three outputs

The same observation and cloud cache generate the spoken WAV, text advisory, and PNG.

Radio request

Noise-relative click detection

HackRF and Airspy backends calibrate to the local noise floor and apply click timing, request windows, and cooldown.

Transmission

USB-relay radio control

The current path pauses SDR receive, closes the radio PTT contact, plays ALSA audio, releases PTT, and resumes receiving.

Audio

Configurable playback

Choose the ALSA output, PTT lead/tail, timeouts, and master playback volume. The current example begins at 85%.

Monitoring

Optional multi-channel listening

One wide HackRF sample can expose nearby configured airband channels for local live listening.

Capture

Optional recorded activity

Store primary-channel WAV clips and JSON metadata. Auxiliary capture can be gated by user-configured aircraft in recent local ADS-B data.

Daily report

Sunrise-aware email

Send once per day after local sunrise plus ten minutes with weather, camera, request times, health, disk warning, and NBM guidance.

Privacy

Public defaults stay generic

No real credentials, aircraft, email addresses, hardware serials, or private copy destinations belong in the committed configuration.

Quality

Regression tests

Automated tests cover weather freshness, cloud request limits, sunrise scheduling, recording, and both transmission paths.

What is not bundled here

The deployment-specific local aircraft/dashboard application is intentionally outside this core GitHub release. Full MyAWOS exposes the files, logs, sockets, and metadata that a separate local UI can consume without making the radio/weather engine dependent on a web application.
