Build in safe stages

Getting started.

Prove the weather, receiver, audio, and relay independently. Enable automatic transmission only after every layer is understood.

Before hardware work: confirm your radio manual, cable pinout, site authorization, and applicable operating rules. Public source ships with transmission disabled.

The installation path

Collect the hardware

Linux computer, WeatherLink Live, HackRF or Airspy, receive antenna, aviation radio, USB dry-contact relay, and a radio-compatible audio/PTT cable.

See hardware and wiring →

Download the source

git clone https://github.com/dennisjamescox/myawos.git
cd myawos/v5-sdr-usb-relay

No GitHub account is required to clone a public repository or download its ZIP.

Create the Python environment

python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp config.yaml config.local.yaml

Configure only what you own

Add your station identifier and coordinates, WeatherLink address, receiver type, primary frequency, and ALSA audio device to the ignored local configuration. Keep real addresses, aircraft, and credentials out of Git.

Generate weather products

python3 weather.py --config config.local.yaml --base "$PWD"
python3 get_clouds_from_awc.py --config config.local.yaml \
  --cache clouds.json --lock .clouds.lock
perl convert_weather_txt_to_wav.pl
perl convert_weather_txt_to_sms.pl
bash generate.sh
aplay current.wav

Calibrate receive-only

python3 click_listen.py --config config.local.yaml \
  --monitor-only --print-levels

Confirm clicks are counted without any PTT action. Adjust gain first; thresholds second.

Test audio and relay separately

Use a controlled RF test arrangement. Play the WAV without PTT, then test the dry contact without audio. Confirm the relay is open at rest and always releases.

Deploy and deliberately enable

Install the service with paths and user adjusted for your machine. Only then change safety.transmit_enabled in the private deployed configuration.

What the download does—and does not do

The repository supplies source, safe example configuration, service templates, tests, voice media, and documentation. It does not silently configure your radio or enable transmission. Hardware-specific audio levels, relay ports, station address, and legal operating details require an operator decision.

For a smaller guided package, use MyAWOS Lite.
